Source-frame planning

Plan a push-in from the crop you have, not the extra picture you wish existed.

A push-in only needs room around the subject when the source image already contains that room. If the source ends at the subject’s shoulder, product edge, or horizon, a stronger move asks the generator to make up the missing scene.

The short answer

Before generating, draw the final crop inside the source image. Keep the subject’s protected details inside that final box, and make the camera move smaller when the box reaches an unknown edge. This turns crop choice into a preflight check instead of a repair after a render fails.

Use a final box, not a vague request for “more motion”

Start from the actual image dimensions. Put a box where the last frame of the move should land. The box is not a promise of a particular model result; it is a constraint you can inspect before generation. If the box cuts through a face, label, hand, skyline, or intended background cue, the shot has no safe crop room for that direction.

  1. Name the protected thing. Pick the detail that must stay readable: an eye line, product label, hand, horizon, or a person’s full silhouette.
  2. Draw the ending crop. Make the final box smaller only until the protected thing still has breathing room on every important side.
  3. Check the approach path. Trace the move from the source frame to the final box. Any edge that must reveal new scenery is an invention risk.
  4. Choose the smaller job. Reduce the push-in, change the direction, or use a roomier source image before writing a more complicated prompt.

Separate crop room from prompt language

Prompt wording can describe a camera job, but it cannot supply a reliable map of pixels outside the source image. When a render invents a shoulder, changes a product boundary, or turns a clean horizon into a new scene, first check whether the requested path had enough source room. Use the frame-crop guide to select a stable input frame, then use the render review sheet to judge the result by visible evidence.

A short preflight question

Ask: “Can I draw the final frame completely inside what I can already see?” If yes, the move has a clear geometric job. If no, the source frame—not the lack of prompt detail—is the first thing to change. For a clean comparison afterward, change only one variable in the one-change test.

Use the push-inThe finishing crop is inside the source, protected details remain readable, and the route never needs unseen edge detail.
Reduce or redirectThe crop touches a tight edge, hides a protected detail, or needs picture information that the source never showed.
