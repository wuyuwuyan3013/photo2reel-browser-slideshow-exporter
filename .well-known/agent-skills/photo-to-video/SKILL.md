# Create a local photo slideshow video

Use this skill when a person wants to turn a sequence of local photos into a slideshow video.

## Inputs

- A sequence of image files supported by the browser.
- An optional duration for each image.
- An optional local audio file or a built-in tone.
- A landscape or vertical output frame.

## Steps

1. Open the Photo2Reel tool.
2. Add the photos and confirm their order.
3. Set per-image timing and the desired frame orientation.
4. Choose whether to include audio.
5. Preview the sequence and start local rendering.
6. Download the resulting video when rendering finishes.

## Privacy and limitations

The source files are read by the browser and are not uploaded by the public tool. Rendering depends on browser media support and local CPU and memory. This skill does not provide server-side processing or an AI generation endpoint.
